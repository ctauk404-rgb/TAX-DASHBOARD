# 위하고 신용카드 매입 자동분류

세무사님이 위하고에 직접 로그인하면, 그다음은 프로그램이 처리합니다.

1. 수임처 → [회계]
2. 자동전표처리 → [신용카드]
3. 구분 '2. 매입', 카드 '전체거래처', 전표상태 '전체' → [조회]
4. 거래처별로 정렬
5. 거래처별로 **유형**과 **차변계정**을 정해서 **전표상태를 '확정가능'** 으로 만듦

**전표전송은 세무사님이 직접 합니다.** 프로그램은 '전송·삭제·마감·취소' 단어가 있는 버튼을 누르지 않습니다.

## 자동 입력: `apply.bat`

`apply.bat` 더블클릭 → 로그인 → 수임처 입력 → 표가 보이면 Enter

1. **미리보기**가 열립니다 (거래처별 현재값 / 제안값 / 근거). 가맹점명·금액이 있으니 PC 에만 두세요
2. 검은 창에 **전표상태 코드별 건수**가 나옵니다. 자동 입력할 코드를 입력하세요 (예: `1,3`)
   - **이미 전표전송된 상태는 반드시 빼세요.** `settings.json` 의 `editable_states` 에 적어 두면 다음부터 묻지 않습니다
3. 입력할 건수와 건너뛸 건수(검토 필요, 계정 코드 모름, 이미 맞음 등)가 나옵니다
4. **1건만 시험 입력** → 위하고 화면에서 그 건을 확인 → `y` 를 누르면 나머지 입력
   - 프로그램은 사람처럼 칸으로 이동해서 입력하고 Enter 를 누릅니다 (유형 `57`/`3`, 차변계정은 계정코드)
   - 값이 바뀌고 위하고 저장까지 확인된 건만 성공으로 칩니다. 3건 연속 실패하면 멈춥니다
5. **전표전송은 하지 않습니다.** 위하고에서 확인하신 뒤 직접 전송하세요

### 되돌리기: `undo.bat`
입력할 때마다 바꾸기 전 값이 `원복_수임처_날짜.csv` 에 기록됩니다.
`undo.bat 원복_수임처_날짜.csv` 를 실행하면 그 값으로 되돌립니다 (전표전송 전에만 의미가 있습니다).

### 미리보기만: `preview.bat`
위하고에는 아무것도 쓰지 않고 미리보기만 만듭니다.

## 분류 규칙 고치기

| 파일 | 내용 |
|---|---|
| `rules.csv` | 가맹점/업종 → 차변계정, 유형. 엑셀로 열어서 줄을 추가하면 됩니다 |
| `settings.json` | 공제 유형 이름(카과), 불공제 계정·업종 단어 목록 |

`rules.csv` 칸 설명
- **수임처**: 비우면 모든 수임처 공통, 적으면 그 수임처에만 적용 (우선)
- **가맹점**: 위하고 '거래처' 칸에 들어 있는 글자 (예: `카카오페이`). 띄어쓰기와 (주)·주식회사는 무시
- **업종**: 업태·종목에 들어 있는 글자 (예: `주유`)
- **차변계정**: 위하고에 표시되는 이름 그대로 (예: `(판)소모품비`)
- **유형**: 비우면 자동 판단

### 판단 순서
**차변계정**: 규칙(수임처 전용 → 공통 가맹점 → 업종) → 위하고 추천값 유지 → 둘 다 없으면 '검토 필요'

**유형**
1. 구분이 간이·면세 → `일반`
2. 규칙에 유형이 있으면 그 값
3. 접대비(기업업무추진비) 계정 → `일반`
4. 세액 0원 → `일반`
5. 업태·종목에 택시·항공·목욕·이발·미용 등 → `일반` + 검토 표시
6. 그 밖 → `카과`

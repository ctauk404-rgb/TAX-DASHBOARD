# 위하고 신용카드 매입 자동분류

세무사님이 위하고에 직접 로그인하면, 그다음은 프로그램이 처리합니다.

1. 수임처 → [회계]
2. 자동전표처리 → [신용카드]
3. 구분 '2. 매입', 카드 '전체거래처', 전표상태 '전체' → [조회]
4. 거래처별로 정렬
5. 거래처별로 **유형**과 **차변계정**을 정해서 **전표상태를 '확정가능'** 으로 만듦

**전표전송은 세무사님이 직접 합니다.** 프로그램은 '전송·삭제·마감·취소' 단어가 있는 버튼을 누르지 않습니다.

## 현재 단계: 분류 미리보기 (위하고에는 쓰지 않음)

`preview.bat` 더블클릭 → 로그인 → 수임처 입력 → 표가 보이면 Enter

1. 위하고가 [조회] 때 받아 온 카드 목록 전체를 읽어서, 거래처별로 **현재 유형·차변계정**과 **제안 유형·차변계정**, 근거를 보여 주는 `미리보기_수임처_날짜.html` 이 열립니다.
   - 주황색 줄: 검토가 필요한 거래처 (계정 미정, 불공제 업종 의심)
   - 파란색 줄: 제안대로 하면 값이 바뀌는 거래처
   - 이 파일에는 가맹점명·금액이 들어 있으니 **PC 에만 두세요**
2. 이어서 조사 안내가 나옵니다. 위하고 표에서 한 건의 [유형] 과 [차변계정] 을 바꾸고 Enter → 다시 원래대로 되돌리고 Enter
   - 전표전송은 누르지 마세요
3. `recon3_결과.json` 만 Claude에게 보내 주세요 (칸 정의·코드값·변경 기록만 있음)

## 분류 규칙 고치기

| 파일 | 내용 |
|---|---|
| `rules.csv` | 가맹점/업종 → 차변계정, 유형. 엑셀로 열어서 줄을 추가하면 됩니다 |
| `settings.json` | 공제 유형 이름(카과), 불공제 계정·업종 단어 목록 |

`rules.csv` 칸 설명
- **수임처**: 비우면 모든 수임처 공통, 적으면 그 수임처에만 적용 (우선)
- **가맹점**: 위하고 '거래처' 칸에 들어 있는 글자 (예: `카카오페이`). 띄어쓰기와 (주)·주식회사는 무시
- **업종**: 업태·종목에 들어 있는 글자 (예: `주유`)
- **차변계정**: 위하고에 표시되는 이름 그대로 (예: `(판)소모품비`)
- **유형**: 비우면 자동 판단

### 판단 순서
**차변계정**: 규칙(수임처 전용 → 공통 가맹점 → 업종) → 위하고 추천값 유지 → 둘 다 없으면 '검토 필요'

**유형**
1. 구분이 간이·면세 → `일반`
2. 규칙에 유형이 있으면 그 값
3. 접대비(기업업무추진비) 계정 → `일반`
4. 세액 0원 → `일반`
5. 업태·종목에 택시·항공·목욕·이발·미용 등 → `일반` + 검토 표시
6. 그 밖 → `카과`

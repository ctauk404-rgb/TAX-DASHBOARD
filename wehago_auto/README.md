# 위하고 신용카드 매입 자동분류

세무사님이 위하고에 직접 로그인하면, 그다음은 프로그램이 처리합니다.

1. 수임처 → [회계]
2. 자동전표처리 → [신용카드]
3. 구분 '2. 매입', 카드 '전체거래처', 전표상태 '전체' → [조회]
4. 거래처별로 정렬
5. 거래처별로 **유형**과 **차변계정**을 정해서 **전표상태를 '확정가능'** 으로 만듦

**전표전송은 세무사님이 직접 합니다.** 프로그램은 '전송·삭제·마감·취소' 단어가 있는 버튼을 누르지 않습니다.

## 새 PC 에서 처음 쓸 때: `setup.bat`

1. GitHub 에서 ZIP 을 받아 압축을 풉니다 (바탕화면 등)
2. **`setup.bat` 더블클릭**
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
   - Python 이 없으면 자동 설치(winget), 이어서 필요한 라이브러리(Playwright) 설치
   - 브라우저는 PC 에 있는 크롬/엣지를 그대로 씁니다 (추가 다운로드 없음)
3. "Setup complete" 가 나오면 끝. 이후 `batch.bat` 등을 쓰면 됩니다
- 자동 설치가 안 되면 [python.org](https://www.python.org/downloads/) 에서 설치 (**"Add python.exe to PATH" 체크**) 후 `setup.bat` 을 다시 실행
- 다른 bat 파일도 Python 이 없으면 `setup.bat` 을 먼저 자동으로 실행합니다
- 기존 PC 의 학습 기록을 쓰려면 기존 폴더의 `data` 폴더, `rules.csv`, `settings.json`, `수임처목록.txt` 를 새 폴더로 복사하세요

## 여러 수임처 한 번에: `batch.bat`

1. `수임처목록.txt` 에 수임처 이름을 한 줄에 하나씩 적습니다 (위하고 수임처 검색에 넣는 이름 그대로, `#` 줄은 무시)
2. `batch.bat` 더블클릭 → **로그인 한 번** → 목록의 수임처를 차례대로 처리합니다
   - 수임처마다: 수임처 검색 → [회계] → 신용카드 → 매입·전체 → 조회 → 분류 → 거래처별 일괄변경 → 수임처 목록으로 돌아감
3. 처음에 한 번만 묻는 것
   - 자동 입력할 **전표상태 코드** (`settings.json` 의 `editable_states` 에 적어 두면 묻지 않음)
   - **시험**: 처음 변경이 있는 수임처에서 거래처 하나로 시험 → 확인 후 `y` → 그 뒤 모든 수임처는 자동 진행
4. 자동으로 안 되는 단계가 있으면 직접 하고 Enter, 또는 **`s` 를 입력하면 그 수임처는 건너뜁니다**
5. 수임처 하나에서 오류가 나도 기록하고 다음 수임처로 넘어갑니다
6. 끝나면
   - `일괄처리결과_날짜.csv`: 수임처별 결과 (완료/일부 실패/건너뜀/오류, 건수, 원복 파일 이름)
   - 수임처별 `미리보기_*.html`, `원복_*.csv`
   - **수임처별·거래처별 일반/카과 현황표**가 열립니다
7. 전표전송은 하지 않습니다. 수임처별로 확인하신 뒤 직접 전송하세요

## 자동 입력: `apply.bat`

`apply.bat` 더블클릭 → 로그인 → 수임처 입력 → 표가 보이면 Enter

1. **미리보기**가 열립니다 (거래처별 현재값 / 제안값 / 근거). 가맹점명·금액이 있으니 PC 에만 두세요
2. 검은 창에 **전표상태 코드별 건수**가 나옵니다. 자동 입력할 코드를 입력하세요 (예: `1,3`)
   - **이미 전표전송된 상태는 반드시 빼세요.** `settings.json` 의 `editable_states` 에 적어 두면 다음부터 묻지 않습니다
3. 입력할 건수와 건너뛸 건수(검토 필요, 계정 코드 모름, 이미 맞음 등)가 나옵니다
4. **거래처 하나만 시험 입력** → 위하고 화면에서 확인 → `y` 를 누르면 나머지 입력
   - 프로그램은 사람처럼 칸으로 이동해서 입력하고 Enter 를 누릅니다 (유형 `57`/`3`, 차변계정은 계정코드)
   - 값이 바뀌고 위하고 저장까지 확인된 건만 성공으로 칩니다. 3건 연속 실패하면 멈춥니다
5. **전표전송은 하지 않습니다.** 위하고에서 확인하신 뒤 직접 전송하세요

### 거래처별 일괄변경 (기본 동작)
recon5 로 확인한 세무사님 방식 그대로 합니다.
1. 표를 거래처순으로 정렬
2. 같은 거래처·같은 값으로 바꿀 줄들을 왼쪽 체크칸에 모두 체크
3. 맨 위 한 줄의 유형(또는 차변계정)을 입력 → 하단 **[일괄변경]** → **[확인]**
4. 위하고가 체크된 줄 전체를 한 번에 저장(`PUT /smarta/saac0105/batch/6/`) → 줄마다 값이 바뀌었는지 확인
- 시험은 2건 이상인 거래처 하나로 먼저 합니다
- 일괄변경이 안 되면 그 거래처는 한 건씩 입력으로 자동 전환합니다
- 되돌리기(undo)는 한 건씩 합니다

### 수임처별 과거 전표 학습 (같은 상호라도 수임처마다 다르게)
예: 주유소 — 화물차·9인승 이상 차량이면 **카과**, 승용차면 **일반**. 그래서 학습은 **수임처 안에서만** 합니다.

**2025년 전표 학습: `learn.bat` (한 번만)**
1. `수임처목록.txt` 에 수임처를 적고 `learn.bat` 실행 → 로그인 한 번
2. 수임처마다 기간을 **2025.01.01 ~ 2025.12.31** 로 바꿔 조회하고, 읽은 전표를 `data/기록.json` 에 저장 (위하고에는 쓰지 않음)
   - 기간(또는 기수)이 자동으로 안 바뀌면 직접 2025년으로 바꾸고 [조회] → Enter, 건너뛰려면 `s`
3. 이후 `batch.bat` / `apply.bat` 이 이 기록으로 판단합니다. 2026년 처리한 전표도 계속 쌓입니다

**판단 순서** (이 수임처의 이미 처리된 전표만 사용)
1. 같은 **카드** + 같은 거래처 (차량별로 카드를 나눠 쓰는 경우)
2. 같은 **거래처**
3. 같은 카드 + 같은 **업종(종목)** — 처음 보는 주유소도 그 카드의 주유가 카과였으면 카과
4. 같은 업종
- 과거 건수 중 한쪽이 80% 이상이면 그 유형(`settings.json` 의 `learn_share`)
- 섞여 있으면(예: 화물차·승용차를 같은 카드로 주유) **'과거 혼재' 검토** 로 남기고 자동 입력하지 않음
- 같은 거래처의 과거 차변계정도 일정하면 따릅니다

**전체 우선순위**: 간이·면세 → rules.csv → 접대비 → **수임처 학습** → 세액 0 → 불공제 업종 → 카과

### 수임처별 · 거래처별 일반/카과 현황: `report.bat`
`data/기록.json` 의 모든 수임처를 모아 `현황_날짜.html` (보기용)과 `현황_날짜.csv` (엑셀용)를 만듭니다.
수임처마다 거래처별 판정(일반/카과), 건수, 금액, 차변계정, 기간이 나오고, 일반과 카과가 섞인 거래처는 주황색으로 표시됩니다.
`apply.bat` 이 끝날 때도 자동으로 만들어집니다.

### 되돌리기: `undo.bat`
입력할 때마다 바꾸기 전 값이 `원복_수임처_날짜.csv` 에 기록됩니다.
`undo.bat 원복_수임처_날짜.csv` 를 실행하면 그 값으로 되돌립니다 (전표전송 전에만 의미가 있습니다).

### 미리보기만: `preview.bat`
위하고에는 아무것도 쓰지 않고 미리보기만 만듭니다.

## 브라우저 화면
- 자동화 창은 **최대화**로 열리고, 위하고 화면이 **창 크기에 맞춰** 그려집니다 (윈도우 배율 125%·150% 도 그대로)
- 기본은 **크롬**입니다. 엣지로 바꾸려면 `settings.json` 의 `"browser"` 를 `"edge"` 로 바꾸세요
  (설정한 브라우저가 없으면 다른 쪽을 자동으로 씁니다)
- 창 크기를 바꾸면 위하고 화면도 따라 바뀝니다. 작업 중에는 창을 건드리지 않는 것이 좋습니다

## 분류 규칙 고치기

| 파일 | 내용 |
|---|---|
| `rules.csv` | 가맹점/업종 → 차변계정, 유형. 엑셀로 열어서 줄을 추가하면 됩니다 |
| `settings.json` | 공제 유형 이름(카과), 불공제 계정·업종 단어 목록 |

`rules.csv` 칸 설명
- **수임처**: 비우면 모든 수임처 공통, 적으면 그 수임처에만 적용 (우선)
- **가맹점**: 위하고 '거래처' 칸에 들어 있는 글자 (예: `카카오페이`). 띄어쓰기와 (주)·주식회사는 무시
- **업종**: 업태·종목에 들어 있는 글자 (예: `주유`)
- **차변계정**: 위하고에 표시되는 이름 그대로 (예: `(판)소모품비`)
- **유형**: 비우면 자동 판단

### 판단 순서
**차변계정**: 규칙(수임처 전용 → 공통 가맹점 → 업종) → 위하고 추천값 유지 → 둘 다 없으면 '검토 필요'

**유형**
1. 구분이 간이·면세 → `일반`
2. 규칙에 유형이 있으면 그 값
3. 접대비(기업업무추진비) 계정 → `일반`
4. 세액 0원 → `일반`
5. 업태·종목에 택시·항공·목욕·이발·미용 등 → `일반` + 검토 표시
6. 그 밖 → `카과`

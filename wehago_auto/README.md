# 위하고 신용카드 매입 자동분류

세무사님이 위하고에 직접 로그인하면, 그다음은 프로그램이 처리합니다.

1. 수임처 → [회계]
2. 자동전표처리 → [신용카드]
3. 구분 '2. 매입', 카드 '전체거래처', 전표상태 '전체' → [조회]
4. 거래처별로 정렬
5. 거래처별로 **유형**과 **차변계정**을 정해서 **전표상태를 '확정가능'** 으로 만듦

**전표전송은 세무사님이 직접 합니다.** 프로그램은 '전송·삭제·마감·취소' 단어가 있는 버튼을 누르지 않습니다.

## 현재 단계: 화면 구조 조사 (1회)

위하고 표를 자동으로 읽고 고치려면, 위하고 표가 어떤 방식으로 만들어져 있는지 먼저 알아야 합니다.
조사 모드는 **위하고 데이터를 읽기만 하고 아무것도 바꾸지 않습니다.**

### 준비 (처음 한 번만)
1. [python.org](https://www.python.org/downloads/) 에서 Python 설치. 설치 첫 화면에서 **"Add python.exe to PATH" 체크**
2. 이 폴더(`wehago_auto`)를 PC에 내려받기

### 실행
1. `recon.bat` 더블클릭 (또는 `python run.py recon --client 팔각도`)
2. Edge 창이 열리면 **위하고에 직접 로그인** → 수임처 목록이 보이면 검은 창에서 Enter
3. 수임처 이름 입력 → 프로그램이 순서대로 화면을 엽니다
   - 자동으로 못 한 단계가 있으면 "직접 해 주세요"라고 나옵니다. 위하고에서 그 단계만 직접 하고 Enter
4. 카드 매입 표가 보이면 Enter → `recon_결과.json` 파일이 생깁니다
5. 이 파일을 Claude에게 보내 주세요

`recon_결과.json` 에는 화면 구조(칸 이름, 버튼 위치)만 들어가고,
**가맹점명·금액·사업자번호 같은 표 내용은 모두 '·' 로 가려집니다.**

## 2차 조사: 표 구조와 저장 방식 (1회)

1차 조사로 알게 된 것
- 위하고 카드 표는 **RealGrid**(그림으로 그리는 표)라서 화면 글자를 직접 읽을 수 없습니다.
- 대신 [조회] 때 위하고가 받아 오는 목록 데이터(704건 등)를 프로그램이 그대로 읽을 수 있습니다.

2차 조사로 알아낼 것
- 표의 각 칸이 데이터의 어떤 항목인지, 코드값(예: 유형 1·2…)이 화면에서 무엇으로 보이는지
- 유형·차변계정을 바꿀 때 위하고가 어떤 방식으로 저장하는지

### 실행
1. `recon2.bat` 더블클릭 → 로그인 → 수임처 입력 (1차와 같음)
2. 표가 보이면 Enter
3. 안내가 나오면 **아무 거래 한 건**에서
   - [유형] 을 다른 값으로 바꿨다가 **원래 값으로 되돌리기**
   - [차변계정] 도 바꿨다가 **원래대로 되돌리기**
   - **전표전송은 누르지 마세요**
4. Enter → `recon2_결과.json` 을 Claude에게 보내 주세요

이 파일에는 칸 정의, 코드값별 건수, 저장 요청의 항목 이름만 들어가고 가맹점명·금액은 들어가지 않습니다.

## 분류 규칙 고치기

| 파일 | 내용 |
|---|---|
| `rules.csv` | 가맹점/업종 → 차변계정, 유형. 엑셀로 열어서 줄을 추가하면 됩니다 |
| `settings.json` | 공제 유형 이름(카과), 불공제 계정·업종 단어 목록 |

`rules.csv` 칸 설명
- **수임처**: 비우면 모든 수임처 공통, 적으면 그 수임처에만 적용 (우선)
- **가맹점**: 위하고 '거래처' 칸에 들어 있는 글자 (예: `카카오페이`). 띄어쓰기와 (주)·주식회사는 무시
- **업종**: 업태·종목에 들어 있는 글자 (예: `주유`)
- **차변계정**: 위하고에 표시되는 이름 그대로 (예: `(판)소모품비`)
- **유형**: 비우면 자동 판단

### 판단 순서
**차변계정**: 규칙(수임처 전용 → 공통 가맹점 → 업종) → 위하고 추천값 유지 → 둘 다 없으면 '검토 필요'

**유형**
1. 구분이 간이·면세 → `일반`
2. 규칙에 유형이 있으면 그 값
3. 접대비(기업업무추진비) 계정 → `일반`
4. 세액 0원 → `일반`
5. 업태·종목에 택시·항공·목욕·이발·미용 등 → `일반` + 검토 표시
6. 그 밖 → `카과`
